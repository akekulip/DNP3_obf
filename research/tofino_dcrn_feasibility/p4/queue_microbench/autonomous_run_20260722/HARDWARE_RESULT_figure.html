DNP3 in-network size normalization — what was actually built and proven

The size axis only, at Level-1: a P4 program (queue_microbench_trace_v1) that pads every frame to a single 128 B state on real silicon. Classification is by a declared input-size class carried on synthetic replay frames — not live DNP3/TCP parsing. No splitting, no timing hold, no metronome, no multi-queue pattern. Every number below is measured, not projected.
