## 1. PRIMARY READOUT — privacy-vs-overhead Pareto knee (the headline figure)
One point per bucket config B∈{native,16,8,4,2,1}, plotted TWICE: mechanism-independent y (I(padded_size;label), Miller-Madow-corrected, permutation-null band) and adversary-instantiated y (size-only balanced acc, repeated-CV 95% CI, chance 0.333). x = mean added bytes/response (+ p95, relative).
Two pre-registered knees: **B*_MI** (Kneedle max-distance-to-chord = most-privacy-per-byte, HEADLINE) and **B*_op** (smallest B meeting: size-only bal-acc 95%-CI upper ≤ 0.40 AND every bucket k≥2 = deployment rec).
**LOAD-BEARING CEILING:** because padding is append-only/up-only and each bucket pads members up to that bucket's ceiling, padded size takes B shared values BUT per-device bucket-OCCUPANCY FREQUENCIES stay device-specific → **I(padded_size;label)=0 reachable ONLY at B=1**; every B>1 leaves residual leakage via occupancy, not size values. Pareto question: how much overhead buys how close to the B=1 MI-floor, does a small B capture most closure [H7]. Convex early knee → Verdict A; MI collapses only at B=1 (huge overhead) or heavy-tail device keeps k=1 → **Verdict B honest negative**, reported not averaged.

## 2. CORRECTNESS GATE (binary prerequisite — no privacy number counts until it passes on rig)

G3 master parse health (0 DNP3 parse/CRC errors at real OpenDNP3 master). G4 no DB corruption (SOE diff: only designated benign/decoy points change, 0 operational). **G5 no-desync (H3): CONFIRM count == native + single event-buffer flush.** G6 transport clean (0 retrans/reset/dup/reorder). G9 segmentation invariant (per-response TCP segment count == native, no padded frame crosses MSS). **G5 + G9 most likely to fail + most threaten the claim** (G5=desync safety; G9=MSS crossing re-introduces packet-count fingerprint). Gates, not metrics.
