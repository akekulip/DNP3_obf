Leak-safe per-transaction J selector vs the fixed-J placeholder
================================================================
compiler : bf-p4c 9.13.1  (--target tofino --arch tna -g)
program  : defense4_twopipe_pipe1_faithful_probe.p4  (pipe-1 half of the faithful two-pipe BOR)

                              INGRESS stages   EGRESS   critical path   logical tables
placeholder (fixed J/flow)         10             0          10              52
leak-safe (this build)             10             0          10              53   (+1)

Fit: 10/12 ingress (stages 0..9), 2 stages of margin under the 12-stage wall. UNCHANGED stage
count and critical path vs the placeholder; +1 logical table.

What changed (selector only; every BOR invariant preserved):
  - Added Random<bit<8>>() rng_bor_j (the Tofino hardware PRNG).
  - One draw per packet: meta.rand8 = rng_bor_j.get();  (placed as its own logical table, stage 0).
  - tbl_bor_codebook key: { hdr.tcp.dst_port : exact }  ->  { hdr.tcp.dst_port : exact, meta.rand8 : range }
    It is now a TCAM range table (mau.resources: 4 TCAM blocks), placed at stage 1.
    Per-flow probability bands over rand8 (0..255) are control-plane action data; widths = weights.

Leak-safety: J is drawn from the hardware PRNG, never from hdr.tcp / DNP3 sequence / BOR epoch /
any on-wire field a passive upstream observer can read. dst_port keys the per-flow PROFILE only.
This is a per-transaction random selection over a bounded codebook (shift -> convolution),
distinct from the earlier fixed-J-per-flow placeholder (which only shifted the distribution).
