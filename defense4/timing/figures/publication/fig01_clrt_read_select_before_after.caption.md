### fig01_clrt_read_select_before_after

Cross-layer response time (CLRT), the interval from the outstation's TCP acknowledgment to its DNP3 application response, with the in-network timing mechanism disabled (Timing OFF) and enabled (Obfuscated), measured master-facing against the physical SEL-751. Left: READ (function 1). Right: the SELECT phase of select-before-operate (function 3), written SBO throughout; these are SELECT observations, not complete SBO transactions. With the timing mode off, CLRT is spread over roughly 1 to 18 ms and differs between the two classes; with it on, both collapse onto the same 4.001 ms policy value. Timing OFF: 999 READ and 488 SBO transactions; Obfuscated: 599 and 499. Each panel's horizontal axis runs to its largest observation, so the full tail is visible. Both arms ran the same unified switch binary with the size-shaping datapath active, so the Timing OFF arm is not an unmodified device baseline and the comparison isolates the timing-mode change.

**Statistics.** Probability-density histograms of per-transaction CLRT, 0.25 ms bins, no smoothing. Cold-start transactions (the first of each TCP connection) are excluded and counted in timing_stats.json under row_accounting. Nothing is clipped: each axis limit is that panel's largest observation.
