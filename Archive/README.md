# Historical material

This tree is historical data, not current operating instructions. Normal builds, tests, source selection and searches
must not depend on it. Use the pre-cleanup Git revision when examining historical layouts or claims.

- tracked/: historical tracked material, with original path/provenance recorded in migration inventory.
- local/: private or originally untracked local material; do not stage it by wildcard.
- paper/ and manual_inputs/: scoped paper/manual-input archive; original tracking status is recorded separately.

Only verified duplicate or proven regenerable copies may be pruned. Do not run scripts found here as current tools.
