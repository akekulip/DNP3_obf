\begin{abstract}
Device fingerprinting is an early step in reconnaissance against industrial control systems. On a
power-grid control network, a passive observer can tell what kind of operation a DNP3 outstation
is performing from the time the device itself takes to answer. Existing traffic obfuscation does
not transfer to this setting. It reshapes flow-level packet sizes and inter-packet times, whereas
the feature that leaks here is a single interval inside one transaction, and it relies on an
encrypted channel to hide the packets it adds, which these plaintext legacy networks do not
provide.

We present a timing-obfuscation framework that runs in the data plane of one programmable switch
placed in front of the outstation. The switch holds the outstation's acknowledgment and its
response, and releases each at a deadline computed from a single anchor, so the interval an
observer records is a value the operator configures rather than the device's own. Because the
switch forwards the packets it received, both endpoints run unmodified and no DNP3 byte changes.

We implement the framework as a P4 program on an Intel Tofino-1 and evaluate it against a
physical SEL-751A protective relay over 63{,}360 DNP3 exchanges. The cross-layer response time
moves to the configured value and its interquartile range falls from 2.8~ms to 0.006~ms, and a
measured policy sweep shows the observable following the configured target while the cost of the
exchange stays fixed. A Random-Forest attacker trained before deployment and applied unchanged
falls from 0.651 balanced accuracy to three-class chance. An attacker that retrains on obfuscated
traffic recovers to 0.651 from the request-to-acknowledgment interval, which bounds what the
mechanism achieves.
\end{abstract}
