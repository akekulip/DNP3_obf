# Corpus

`lin_ndss2020_defrec.pdf` is Dr. Lin's own NDSS 2020 paper, downloaded from
https://www.ndss-symposium.org/wp-content/uploads/2020/02/24365-paper.pdf on 2026-09-16 and used
as the primary style corpus for the NDSS adaptation. It is a third-party publication and is not
redistributed here: the PDF is deliberately left untracked, and `lin_ndss2020_style_card.md`
records only its structure and rhetoric, never its content. Re-download it from the URL above if
you need it.
