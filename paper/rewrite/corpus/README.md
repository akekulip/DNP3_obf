# Reference corpus

This directory holds local reading copies used during paper review. PDFs are excluded from Git;
the repository keeps citations, style notes, and derived page images only.

| Local file | Use |
|---|---|
| `lin_ndss2020_defrec.pdf` | Dr. Lin's NDSS 2020 paper and primary voice reference. See `lin_ndss2020_style_card.md`. |
| `references/device_fingerprinting_2016.pdf` | Device-fingerprinting reference used for attacker-literature review. |
| `references/ditto_2022.pdf` | NDSS 2022 traffic-obfuscation reference for mechanism-figure review. |

The DefRec copy is downloaded from <https://www.ndss-symposium.org/wp-content/uploads/2020/02/24365-paper.pdf>.
The downloaded copies are for local research use and are not redistributed by this repository.
