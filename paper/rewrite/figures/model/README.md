# Model figure published into the manuscript

`fig_m01_release_timeline` is generated by
`defense4/timing/audit_current/tools/make_model_figures.py` into
`defense4/timing/figures/model/` and copied here for the manuscript to include.

Copies drift silently, so `FIGURES.sha256` covers the three authoritative artefacts, the vector
PDF, the figure-data CSV and the caption. Verify with `sha256sum -c FIGURES.sha256` in this
directory. The `.png` preview is not gated because Agg raster bytes vary with the interpreter
build, and the `.provenance.json` sidecar is not gated because its `source_commit` field changes
with every commit by design.

To refresh: re-run the generator, copy the artefacts here, and rewrite this manifest.
